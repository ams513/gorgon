Quickstart: your first playable game in 5 minutes

Build a game. Share it as one file. One install, endless ideas.

Stark World Engine is a game builder that runs in your web browser, but everything stays on your own computer. No account, no subscription, no internet needed. A small program on your computer serves the studio to your browser, and only your computer can reach it.

On Steam? Press Play in your Steam library; your games are in Documents\Stark World Engine\My_Games. Skip Step 1 below. If something is missing or damaged, use Steam > Stark World Engine > Properties > Installed Files > Verify integrity of game files.

Stark World Engine Free has the whole builder; its HTML5 cartridges export the first level and show a small closable "Made with Stark World Engine" note. Pro and Studio come activated (the key is already in the folder; nothing is e-mailed) and export every level.

You need:

  • A current browser with WebGL2: Chrome, Edge or Firefox (Safari 15+ also has WebGL2).
  • Windows 10 / 11: nothing else. Python is built into the download.
  • macOS and Linux: Python 3.10 or newer (free, from python.org or your package manager).

Step 1: Unzip

Unzip the download (for example Stark_World_Engine_Pro_v28.7.zip) somewhere you own: your Desktop or Documents folder is fine. You get one folder. Keep everything in that folder together.

Tip: don't run it from inside the zip preview. On Windows, right-click the zip > Extract All... first. Avoid C:\Program Files and cloud-synced folders (OneDrive, Dropbox): the studio needs to save your games there.

Step 2: Start the studio

Windows 10 / 11

Double-click START_STARK_WORLD_ENGINE.bat in the folder.

  • A small black window opens. It finds the built-in Python, runs a quick setup check, then starts the studio and opens your browser. Leave the black window open while you work; close it when you're done.
  • If Windows shows "Windows protected your PC", click More info > Run anyway (see Troubleshooting).
  • If the setup check finds a problem, it says exactly what to do. For example, if the folder can't be written to, press Y and it copies itself to your Documents folder and starts from there.

macOS

  1. If you don't have Python 3.10 or newer: go to python.org > Downloads, download the macOS installer and click through it.
  2. Double-click start_stark_world_engine.command in the folder. The first time, macOS may refuse because it isn't from the App Store: right-click the file > Open > Open.
  3. A Terminal window opens, runs the setup check and starts the studio. Leave it open while you work.

(If the launcher can't find Python, it opens python.org for you and tells you what to do.)

Linux

Most distributions already have Python 3. Check in a terminal with python3 --version; if it's below 3.10, install a newer one (for example sudo apt install python3). Then, in a terminal in the folder:

bash start_stark_world_engine.sh

Your browser opens at an address like http://127.0.0.1:8505 (or the next free number up to 8520). The address 127.0.0.1 means "this computer only".

If the browser doesn't open by itself, copy the address printed in the black/terminal window into your browser. Something not right? Press ? in the studio and click Fix my setup.

Step 3: Play a starter game (1 minute)

The studio comes with three starter games in the drop-down at the top. On your first visit a short tour offers Play a starter game now.

  • Firefly Fen (3D): a glowing swamp with villagers, quests and a boss.
  • Summit Snack Run (3D): a sunset mountain adventure.
  • Lantern Leap (2D): a platformer through sunken ruins.

Pick one, then click ▶ Play at the top (or press Ctrl+Enter).

  • 3D controls: WASD to move, Space to jump, J or click to attack, E to talk or open chests, drag the mouse to look around.
  • 2D controls: A/D to move, Space to jump, stomp enemies, reach the flag.
  • Everywhere: L quest log, I bag, H drink a potion, Esc menu (three save slots and options).

Click Build (or press Ctrl+Enter again) to go back to editing. Press ? to see every shortcut.

Step 4: Let the studio make you a game (1 minute)

  1. Click Make me a game at the top left.
  2. Pick a theme (for example Frozen Kingdom) and a size: Snack is one level, about 15 minutes of play.
  3. Click Make it and play!

You're dropped straight into a complete little adventure with people to talk to, quests, monsters and a boss. It's saved in your games list, and you can change anything in it.

Step 5: Make your own (3 minutes)

  1. Click New 3D world.
  2. Type a name in the Name box (for example "My First Island").
  3. Click a Living World Mood along the top, for example Sub-Zero Aurora. The whole world relights instantly.
  4. In the Tools tab on the right, pick Tree and click on the ground a few times. Then pick Crystal and place 5 crystals: these are what the player collects. Add one or two Slime creatures for a bit of danger.
  5. Click Save (the studio also autosaves a few seconds after each change).
  6. Click ▶ Play. Collect every crystal to see "World complete!".

You just made a playable game. Ready for more? Place a Person, then open the Quests tab and click Fetch: your person now has a quest and dialogue. See Quests, people, items.

Step 6 (optional): Activate your key

Your copy works fully without a key. A key registers your copy and, on the Pro and Studio editions, unlocks the Godot 4 and UE5 project exporters.

  1. After buying you receive one line of text that starts with GS1-.
  2. In the studio, open the Export tab on the right.
  3. Paste the whole key into the Activate box and click Activate.

Or: save the key as a file called key.txt in the same folder as studio_app.py. The studio reads it when it starts.

Activation is checked on your computer only. Nothing is sent anywhere.

Step 7 (optional): Share your game

Open the Export tab and click HTML5 cartridge. Stark World Engine writes one .html file into My_Games/<your game>/export/. Double-click it and your whole game (levels, quests, saves and all) runs in any modern browser, offline. Send it to a friend or upload it to itch.io (see Exporting).

Studio edition: the creator suite

Bought the Studio edition? Double-click SETUP_STARK_WORLD_ENGINE.bat for a 5-minute guided setup of OBS, your camera and mic, the phone remote and your first auto-edited clip. See The creator suite.

Next: the User Guide explains every feature, and Tutorials walks you through five complete projects. Something not working? See Troubleshooting.

1. What Stark World Engine is (and isn't)

Stark World Engine is an offline game builder for 3D and 2D adventure games that runs in your browser, plus (in the Studio edition) a creator suite that helps you film, edit and publish videos about your games.

  • It runs on your computer. The studio listens on 127.0.0.1 (this computer only). No account, no cloud, no subscription. Nothing you make is uploaded anywhere.
  • It makes stylized games. Worlds use bundled CC0 models and textures (or your own glTF imports) with PBR lighting, HDRI skies, fog and weather moods. It runs in a browser; it is not a replacement for a full engine.
  • Games can be real adventures. Quests, people to talk to, items and equipment, experience and levels, enemies and bosses, several levels in a row and three save slots all run inside the game you export.
  • It is a fast way to start. When you want a full engine, the Pro and Studio editions export your world to Godot 4 or Unreal Engine 5 as a starting scene you can keep building on.

2. Starting the studio

How to start
WindowsDouble-click START_STARK_WORLD_ENGINE.bat. Python is built in (in the runtime folder), so there is nothing else to install.
macOSDouble-click start_stark_world_engine.command. The first time, right-click it > Open > Open, because it doesn't come from the App Store. Needs Python 3.10 or newer from python.org (see the Quickstart).
LinuxIn a terminal in the folder: bash start_stark_world_engine.sh. Needs Python 3.10 or newer from your package manager.

A small window opens. Leave it open while you work: it is the studio's engine. Close it (or press Ctrl+C in it) when you're done. Your browser opens the studio at http://127.0.0.1:8505 (or the next free port up to 8520).

The setup check

Before the studio starts, the launcher runs a quick setup check (doctor.py). It looks for the usual first-install problems and tells you, in plain words, how to fix them:

  • running straight from inside the zip (it offers to open the folder with the zip so you can extract it);
  • a folder where the studio can't save, such as Program Files (press Y and it copies itself to your Documents folder and starts from there; the original isn't touched);
  • a very long folder path, or a folder inside OneDrive, Dropbox, iCloud or Google Drive (a tip, not a stop);
  • missing or damaged program files (for example, removed by an antivirus);
  • the built-in Python on Windows (it repairs one small settings file by itself and keeps a backup);
  • whether a port between 8505 and 8520 is free, and whether the studio is already running (then it just opens your browser to it);
  • whether Chrome, Edge or Firefox is installed, low disk space, and a computer clock that looks wrong;
  • whether your license key file is valid;
  • Studio edition: whether FFmpeg and OBS are installed and whether the phone hub is allowed through the firewall.

Problems marked [STOP] must be fixed first; [TIP ] items are advice and the studio starts anyway. Everything is also written to doctor.log in the folder.

Inside the studio, press ? (or click the ? button at the top) and click Fix my setup to run the same checks at any time.

3. The studio screen

When the studio opens you'll see:

  • Top bar: Make me a game, your games list, a level picker (shown when a game has more than one level), New 3D world, New 2D world, the Name box, Save, Undo, Redo, Build, ▶ Play, the language picker and the ? button. A small status text shows what just happened ("Saved", "Export ready", or "edited - autosave in a moment").
  • Mood bar: the five Living World Moods. Click one to relight the level you're editing.
  • The stage: your world, live.
  • Side panel tabs: Tools, World, Quests, Dialogue, Items, Logic, Pixel Art, SFX Forge, Tune, Assets, Learn, Export.

Languages: EN, ES, FR, DE, PT, IT, JA, ZH (English, Spanish, French, German, Portuguese, Italian, Japanese, Chinese). Pick from the drop-down at the top; the studio remembers your choice. The main buttons and tabs are translated; the tool palette, editor panels and in-game text are in English.

First visit: a short three-step tour offers Play a starter game now or Make me a game. Click Skip tour to hide it for good.

4. Make me a game

Don't want to start from an empty world? Click Make me a game at the top left.

  1. Pick a theme: Spooky Swamp, Sky Islands, Frozen Kingdom, Lava Fortress, Sunken City or Cozy Village.
  2. Pick a size: Snack (1 level, about 15 minutes), Evening (3 levels, about an hour) or Epic (6 levels, a few hours).
  3. Optional: type a Seed. The same seed and theme always give the same game, so you can share a seed with a friend. Leave it empty for a surprise.
  4. Optional: tick 2D platformer instead of 3D.
  5. Click Make it and play!

The studio builds a complete game: villages with people who give quests, monsters, treasure chests, keys and locked doors, checkpoints, portals between levels and a boss at the end (bigger games also mix in side-scrolling 2D levels). It is saved straight away and you start playing. Press Build (or Ctrl+Enter) to change anything: it's an ordinary game you can edit like any other.

5. Building 3D worlds

  1. Click New 3D world (or pick a game from the list, or use Make me a game).
  2. Give it a name in the Name box.
  3. Open the Tools tab, pick something, then click the ground to place it:
    • Nature: Tree, Rock, Ruin, House, Lamp (glows at night), Crystal (collectible).
    • Creatures: Slime (chases you), Archer (keeps its distance and shoots), Brute (slow, tough, smashes the ground), Wisp (fast floating spirit), Boss (a big enemy with a health bar and special attacks).
    • Story: Person (someone to talk to), Item (something to pick up), Chest (opened with E), Locked door (needs a key), Portal (to the next level), Checkpoint (heals and saves progress), Player start.
    • Edit: Select / move (click a thing to edit it, drag to move it) and Erase.
  4. With Select / move, click a placed thing to edit it in the panel: a person's name, id and dialogue; an enemy's kind, name, health and wander radius; which item a chest holds and how much gold; which key opens a door; where a portal leads and which quest unlocks it; size and rotation.

Good to know

  • In Build mode: drag to turn the camera, mouse wheel to zoom, WASD to move the camera, Q / E to turn it, Delete removes the selected thing.
  • A level can hold up to 5,000 objects, and a game up to 25 levels.
  • Your games live in the My_Games/ folder next to the studio, one folder per game, each with a world.json file.

Copy, paste, duplicate and snap

  • Select a thing (Select / move), then Ctrl+C copies it, Ctrl+V pastes a copy 2 metres away and Ctrl+D duplicates it. The inspector has the same Duplicate, Copy and Paste buttons. Copies of people, doors and enemies get their own new id (and people a numbered name), so triggers and conversations still point at the right one.
  • Snap (next to Drone in the Tools tab): off, 1 m, 2 m or 4 m. Things you place or drag land on that grid (3D levels). The choice is remembered on this computer.
  • In 2D levels only people can be copied; tiles are painted with the Tools.

Drone mode and postcards

  • Drone (P): a slow cinematic camera flight with letterbox bars. Great for screenshots and trailers. Press P again (or click the button) to stop.
  • Postcard PNG: saves a picture of the current view into My_Games/<game>/postcards/.

6. Building 2D worlds

  1. Click New 2D world. You get a flat ground, a start point and a goal flag.
  2. In the Tools tab, pick a tile and click tiles on the stage to paint:
    • Tiles: Ground, Pearl (collectible), Spike, Water (swim through it), Flag (goal: next level or victory), Exit (swirling exit to the next level), Start.
    • Creatures: Slime (stomp it), Archer (shoots at you), Boss (stomp it several times).
    • Story: Potion, Key, Locked door, Checkpoint, Person.
    • Edit: Select (click a person to edit them) and Erase.
  3. Save, then ▶ Play. Move with A/D (or arrows), jump with Space.

Tip: draw your own hero in the Pixel Art tab and click Use as player sprite (see Pixel Art Canvas).

8. Quests, people, items, XP, enemies and campaigns

Everything in this section works in the studio's ▶ Play mode and in exported HTML5 cartridges.

8.1 Quests

Open the Quests tab. Click Fetch, Hunt, Talk, Explore or Escort to add a ready-made quest to the level you're editing, then change it:

  • Title, Description and Given by (a person, or "starts by itself").
  • starts when the level begins and finishing it wins the game.
  • Steps, each one of: Collect items (optionally "hand them over"), Defeat enemies (any, or one kind, or one named enemy), Talk to someone, Go to a place (click Pick the spot on the map), Escort someone. Add more with + step.
  • Reward: XP, gold and an item.

People who have a quest for the player show a gold !, and a gold beam points the player to the next objective. Tip: place a Person first, then click Fetch: you get the quest and that person's dialogue in one go. Write the giver's lines for me rewrites the offer and thank-you lines at any time.

8.2 People and dialogue

Place a Person, select it, and click Write dialogue for this person (or Give them a quest). The Dialogue tab shows the conversation:

  • A conversation is a set of lines. Each line has a speaker and text, and up to 8 answers.
  • An answer can end the talk or go to another line, and can also start quest, finish quest, give item or take item.
  • Say something different when... rules pick the first line depending on whether a quest is done, in progress or not started, or whether the player has an item.
  • + line, + answer, + rule, New and Delete this dialogue do what they say.

While playing, walk up to a person and press E to talk; press 1-4 to pick an answer.

8.3 Items and equipment

The Items tab lets you make your own items with + new item: Quest item, Potion / food (heals), Key, Equipment (weapon, armour, boots or charm, with attack, defence and max HP bonuses) or Treasure (turns into gold). There are also built-in items, such as Crystal, Potion, Elixir, Old Key, swords, armour, boots and a charm. Place items with the Item or Chest tool.

While playing, press I for the bag and H to drink a potion.

8.4 Enemies and bosses

Enemies wander, notice the player, chase and attack. Each kind fights differently (see the tool list above), and a Boss has its own health bar and special attacks. Hits use hit-stop and screen-shake so they feel punchy. On a quest, Defeat enemies can count any enemy, one kind, or one enemy you gave an id.

8.5 XP, levels and abilities

Defeating enemies and finishing quests earns XP. Each new level restores health and makes the player stronger, and some levels unlock an ability:

LevelAbilityKey
2DashShift

4Star Bolt (a ranged shot)F

Falling in battle sends the player back to the last checkpoint and costs 10% of their gold.

8.6 Multi-level games (campaigns)

A game can have several levels. In the World tab, under Levels, click + 3D level, + 2D level or Duplicate this level; Up moves a level earlier and X deletes it. Use the level picker at the top to choose which level you're editing.

Portals (3D) and the flag or exit (2D) take the player to the next level. A portal can also lead to a specific level and stay closed until a quest is finished. XP, items and gold carry over from level to level.

8.7 How the player wins

  • In a game with quests: by finishing the quests marked finishing it wins the game (or, if none is marked, all quests). A dialogue answer can also end the game.
  • In a 3D game without quests: by collecting every crystal.
  • In 2D: by reaching the flag on the last level.

8.8 The Logic tab: when / then blocks

Open the Logic tab. Each trigger is a card: WHEN something happens on this level, THEN a list of blocks runs in order. It works in Play mode and in the exported game.

WHEN can be: the player enters or leaves an area (type X, Z and the radius, or press Pick on map), the level starts, the player talks to someone, an enemy is defeated (a particular one by its Id, or any of a kind), the player picks up an item, a flag is set, a quest is finished, or some seconds have passed. An optional IF line adds a condition (the player has or lacks an item, a quest is finished or active, a flag is set, or a level is reached). Only once is on by default; switch it to every time for things like a healing spring.

THEN blocks: open, close or toggle a door; play a sound (with a caption for subtitles); start a conversation; show a line of text; set or clear a flag; give or take an item; change gold; give XP; heal; start or finish a quest; play a cutscene; move the player; go to another level; win the game; unlock an achievement; shake the screen; wait some seconds. Use the arrow to move a block up and x to remove it. A conversation or cutscene block makes the list wait until it is over.

Tips:

  • To open a door from a trigger, select the door in the Build tab and look at its Id (the Logic tab gives unnamed doors an Id for you). Setting Who can open it to Only a trigger (sealed) makes it ignore keys; pressing E says it will not budge.
  • Flags are just names you invent (for example met_the_smith). Dialogue answers can also set flags, so a conversation can drive a trigger.
  • In 2D levels area triggers use tile columns and rows; type them in (Pick on map is 3D only).
  • Dialogue answers can also open a door, play a cutscene, unlock an achievement or open a shop (door, cutscene, achievement, shop in the world file).

8.9 Cutscenes

In the Logic tab, Cutscenes: press + new, then add steps. Every step has a time in seconds and one action:

  • Camera move: where the camera goes (X, Z, height), what it looks at, and how long it takes. Use editor view copies the camera you are looking through in Build mode.
  • Show a line of text (a subtitle with a speaker name), Walk someone (a person, an enemy or player) to a spot, Play a sound, Fade the screen, Shake the screen, and the quick blocks (flag, give, take, gold, XP, heal, door, move the player, achievement).

While a cutscene plays the player cannot move, black bars slide in, and Esc / Space / Enter skips it (turn that off per cutscene with Esc skips it: no). Skipping still applies what the rest of the cutscene would have done (flags, items, where people end up). Afterwards a flag named cut_<id> is set, so a trigger can follow it. Test it in Play runs it right away. Start one from a THEN block or a conversation answer.

Limits: on 2D levels cutscenes play text, sounds, fades, walking and the quick blocks, but the camera steps do nothing.

8.10 Behaviours and shops

Select a person or enemy in the Build tab (3D levels).

  • People: Stands still, Patrols a path (add points with + add point on map), Follows the player, Runs away from the player (set the radius), or Companion (follows and fights nearby enemies, a little each second). Companions and followers wait in their level; they do not travel through portals.
  • Enemies: Wanders (the old behaviour), Patrols a path, Guards its post (never chases far from it) or Runs when hurt. Keep a patrol path within about 25 metres of where the enemy stands.
  • Shops (people, 2D and 3D): choose Buys and sells, then + item for sale. Leave the price empty for an automatic price (from the item's Shop value in the Items tab, or its gold, heal and attack numbers). Leave stock empty for unlimited. The shop pays a share of an item's value when the player sells (default one half; keys and quest items are never bought). Talk to the person with E: a person with a shop but no conversation opens the shop at once; with a conversation, an extra answer Show me your wares appears at the end.

8.11 Variables and on-screen counters

A variable is a named number the game keeps, such as coins, lives or keys_found. In the Logic tab, under Game rules > Variables, press + variable. Each one has an Id (used by blocks), a Name shown to players, the number it Starts at, an optional Lowest and Highest (it never goes past them; empty means no limit), and On screen: hidden, number or number / highest (for example Lives 3 / 5). Shown variables appear in the player's corner panel. A game can have up to 30.

  • Change one with the THEN block Change a variable: add, subtract, set to, or random number from (a whole number between the two you type, both included). The block also works in cutscenes, and a conversation answer can change a variable (var, op, num in the world file).
  • Test one with an IF line (a variable compares: is equal to, is not, is less than, is at most, is more than, is at least) or with the WHEN a variable reaches a value.
  • Variables are saved in the player's save slots and come back when they load. Renaming a variable's Id updates the blocks that use it.

8.12 More WHEN and IF lines

  • Every few seconds (repeats): runs again and again while the level is played. It pauses while a menu, a conversation or a cutscene is open. At least half a second.
  • The player presses a key: a letter, a digit, Space, Enter or an arrow key. Honest note: on phones and gamepads only the keys the game already uses (moving, Space, E, J and the rest) can be pressed, so pick one of those if the game must work everywhere.
  • A variable reaches a value: fires when the test becomes true (for example coins is at least 10). With Only once: every time it fires again each time the test turns true after being false.
  • IF random chance (%): the trigger only runs that percentage of the time, for a surprise or a rare drop.

9. The look

The 3D view is drawn with WebGL2, right in the browser (new renderer in 28.5): PBR materials (albedo, normal, roughness/metal, occlusion), image-based lighting from HDRI skies, soft cascaded sun shadows, screen-space ambient occlusion, bloom, ACES tone mapping and colour grading per mood, height fog that glows toward the sun, a textured terrain that blends grass, dirt paths, rock, sand and snow, grass and trees that sway in the wind, water with refraction, reflections and shore foam (ice in the Sub-Zero mood), point lights from lamps and crystals, and FXAA (TAA on High). Levels with a day-night cycle blend between a day, a sunset and a night HDRI sky and move the sun.

Graphics presets (Esc menu > Graphics, or the menu on the Build performance meter): Low turns off shadows (and so soft-shadow filtering), ambient occlusion, bloom, TAA, normal maps and the image-based lighting bake (it uses a simple sky/ground light instead), draws fewer plants, renders at half resolution and loads textures lazily: small copies, after the first frames, one per frame. It is meant for older laptops and software rendering. Medium is the everyday preset; High adds a third shadow cascade, softer shadows, screen-space reflections on water and TAA. Auto starts from a hardware check made on first start (software rendering or an old integrated chip: Low; a GeForce RTX or similar card: High; anything else: Medium) and steps down after the world has loaded if it runs slowly. Picking Low, Medium or High always overrides the check.

Performance meter (Build mode, top right of the 3D view): the measured time to draw one frame over the last second on your computer, for the preset in use. Green is smooth (45+ fps), amber is playable (25-45 fps), red is slow: remove some objects or pick a lower preset.

The art. Characters, houses, trees, plants and rocks are real glTF 2.0 models made by artists and released as CC0: Quaternius (Universal Base Characters, Universal Animation Library, Medieval Village MegaKit, Stylized Nature MegaKit) and Poly Haven (HDRI skies, ground and brick textures). The characters' outfits were painted onto the Quaternius base bodies by our own tool. All of it is listed in assets/library.json and assets/CREDITS.txt, and every export credits the art it uses.

Your own art: the Assets tab. Drop a .glb (or a .gltf with its .bin and textures), PBR textures (.png / .jpg; albedo, normal, ORM/roughness, metallic and AO are recognised by their file names) or an .hdr sky. Give it a name, a size, the licence and who made it, then press Import. It is stored in My_Assets/ next to My_Games/, and Place puts it in your world (an .hdr becomes the level's sky). Files that need Draco or meshopt compression are refused with a note: export them again without compression.

Honest note: this is a stylized look designed to run in a browser. It is not a replacement for a full engine; for complex physics or console builds, export to Godot or UE5 and continue there.

16. Music and sound

Soundtrack: in the World tab, click Make a soundtrack. The studio composes an original looping tune (about 40 seconds) that matches the mood of the level you're editing. It's made from scratch on your computer, so it's yours to use. It takes a few seconds (up to about 20 seconds on a slower PC), is saved as My_Games/<game>/assets/soundtrack.wav and plays in ▶ Play mode. Listen plays it, Make a new soundtrack replaces it and Remove takes it off the game.

Honest note: the soundtrack plays in the studio. Exported HTML5 cartridges stay small and do not carry the WAV file; it stays in your game's assets/ folder for videos or for a Godot/UE5 project. For music inside the exported game, use the Tune Maker.

Tune Maker (Tune tab): a grid of 16 or 32 steps. The top 12 rows are notes (Cheerful pentatonic, Major or Minor, in a low, middle or high octave), the bottom rows are Kick, Snare and Hat drums. Click squares to place notes, Listen to loop it, change the speed (60 to 200 beats per minute), the sound (Retro, Soft, Flute or Bright) and the volume, or start from Example tune. The tune is stored in the game itself (a few hundred bytes), loops in ▶ Play mode and inside the exported HTML5 game, and stops when the player turns sound off in the menu. While a tune is set it replaces the soundtrack file in Play mode. If you also built a game audio pack for the export, the pack's music plays in the exported game instead of the tune.

Sound effects for jumping, coins, hits, quests, level-ups, doors, portals, talking and magic are built in, and you can reshape each of them in the SFX Forge.

What you get: an Unreal Engine 5 project in My_Games/<game>/export/ue5/ that builds your level inside the Unreal Editor with a high-end setup already switched on:

How to open:

  1. Install Unreal Engine 5.4 or newer from the Epic Games Launcher (free Epic account). Stark World Engine never downloads it for you.

Tutorial 1: Your first adventure in 10 minutes

You need: the studio running (see the Quickstart). Time: about 10 minutes.

The idea: a lantern keeper's island at night. Talk to the old keeper, find the scattered crystals and avoid the swamp creatures.

Starting the studio

What the setup check's messages mean

When you start Stark World Engine, the black window (Terminal on Mac/Linux) prints "Setup check: N of N OK." and lists anything that needs attention:

  • [STOP] must be fixed before the studio starts. The window says exactly how.
  • [TIP ] is advice. The studio starts anyway.
  • [FIXED] means it repaired something by itself (for example the built-in Python's settings file; a backup is kept as .bak).
  • [NOTE] is just information, for example "Stark World Engine is already running - opening it in your browser".

The sections below cover each message.

"Stark World Engine has to be extracted from the zip first"

You double-clicked the launcher inside the zip preview, so Windows only gave it a temporary copy and your games would be lost. Press Y to open the folder with the zip, right-click the zip > Extract All... > Extract, then double-click START_STARK_WORLD_ENGINE.bat in the new folder.

On a Mac, the same check catches macOS running the app from a hidden read-only copy: move the Stark World Engine folder out of Downloads (for example into Documents) with Finder and start again.

"Stark World Engine is in Program Files..." / "This folder is read-only..."

The studio needs to save your games next to itself. Press Y when asked: it copies itself to Documents\StarkWorldEngine (or your user folder if Documents is synced) and starts from there. The original folder isn't changed; delete it later if you like. Or move the folder yourself to somewhere you own, such as Documents or the Desktop.

"The folder path is very long" / "...inside a syncing folder"

Both are tips. Windows has trouble with very long paths, and OneDrive, Dropbox, iCloud or Google Drive can lock or pause files while you save. It works, but for a smooth ride move the folder to Documents\StarkWorldEngine (a folder that isn't synced).

"Stark World Engine files are missing or damaged"

Usually an antivirus quarantined a file right after unzipping. Restore it (Windows: Windows Security > Virus & threat protection > Protection history, pick the Stark World Engine item > Restore or Allow on device), or download the zip again from your purchase page and extract it into a new folder. Copy your My_Games folder across. See also My antivirus flagged or removed a file.

"Stark World Engine is already running - opening it in your browser"

Nothing is wrong: a studio from this folder is already open, so the launcher just opens your browser to it. To restart the studio, close its other black window first.

"All ports 8505-8520 are in use by ..."

The studio needs one free port between 8505 and 8520. The message names the programs using them. Close them (often several old studio windows), or restart the PC, then start again. Advanced: python studio_app.py --port 8600 picks a port yourself.

"No Chrome, Edge or Firefox found"

The studio opens in your web browser and works best in a current Chrome, Edge or Firefox (all free). Install one and start again.

"Low disk space" / "This computer's clock looks wrong"

Free up at least 1 GB for saves and exports. A wrong clock doesn't break anything, but save dates and backups look odd: turn on Set time automatically in Windows Settings > Time & language (Mac: System Settings > General > Date & Time).

"Your key (key.txt) is not valid, so the studio runs as Free"

Nothing is lost. See License keys below.

Windows: "This PC doesn't have it yet" (Python)

The download includes its own Python in the runtime\python folder, so this only appears if that folder is missing or blocked (usually by an antivirus, or because the zip wasn't fully extracted).

  • Press Y: the launcher fetches the official Python 3.12.10 from python.org (about 11 MB), checks it, and keeps it inside the Stark World Engine folder only. No admin rights needed; nothing else on your PC changes.
  • Or press N and install Python yourself: python.org > Downloads, run the installer, tick "Add python.exe to PATH" on the first screen, then double-click START_STARK_WORLD_ENGINE.bat again.
  • Or extract the zip again into a new folder, so the built-in Python is complete.

"The bundled Python could not start"

The launcher then tries an installed Python instead. To fix the built-in one, extract the zip again into a new folder (and check your antivirus's quarantine).

"The studio stopped unexpectedly"

The black window then shows the last lines of launcher.log. Closing other Stark World Engine windows and starting again usually fixes it. If not, send those lines to the seller (see Still stuck?).

macOS: the launcher won't open, or says Python isn't installed

  • "Cannot be opened because it is from an unidentified developer": right-click start_stark_world_engine.command > Open > Open. You only need to do this once.
  • "isn't installed on this Mac yet": the launcher opens python.org for you. Download the macOS installer, click through it, then double-click the launcher again. (Optional: in the Python folder in Applications, double-click Install Certificates.command; the studio itself never goes online.)

Linux: "Stark World Engine runs on Python 3.10 or newer"

Browser and graphics (WebGL2)

The stage is black or shows a WebGL error

The 3D builder needs WebGL2. When it isn't available, the studio opens a help card by itself ("3D graphics are switched off in this browser"). 2D worlds still work.

  1. Use a current Chrome, Edge or Firefox.
  2. Turn hardware acceleration on: Chrome/Edge Settings > System > "Use graphics acceleration when available", then restart the browser. Firefox: Settings > General > Performance, untick "Use recommended performance settings" and tick "Use hardware acceleration when available".
  3. Check WebGL2: visit chrome://gpu (Chrome/Edge) and look for "WebGL2: Hardware accelerated", or about:support in Firefox.
  4. Update your graphics driver (NVIDIA, AMD or Intel website, or Windows Update > Advanced options > Optional updates).
  5. Remote desktop sessions and some virtual machines don't provide WebGL2. Run the studio on the machine directly.

It's slow or stuttery

  • While playing, press Esc and set Graphics to medium or low.
  • Close other heavy tabs and apps.
  • On laptops, plug in power and choose the high-performance graphics: Windows Settings > System > Display > Graphics, add your browser, choose High performance.
  • Very dense worlds: thin out trees and rocks a little. Fewer, well-placed objects often look better anyway.

No sound

  • Exported HTML5 cartridges don't include the soundtrack WAV. A tune made in the Tune tab does play inside exported games.
  • While a Tune is set, it replaces the soundtrack in Play mode. Clear the Tune to hear the soundtrack again.
  • "The soundtrack maker is not available in this copy": music_engine.py is missing from the folder. Extract the zip again into a new folder.
  • Making a soundtrack can take up to about 20 seconds on a slower PC. Wait for "Soundtrack ready".

The interface is in the wrong language

Creator suite (Studio edition)

My phone can't reach the hub

  1. Phone and PC must be on the same Wi-Fi / home network. Guest networks often block devices from seeing each other.
  2. Run the Setup Wizard (SETUP_STARK_WORLD_ENGINE.bat) and go to Your phone remote. If the hub isn't running, click Start it. If the phone says it can't connect, click Allow on my home network and click Yes on the Windows prompt (it may blink in the taskbar). This adds one firewall rule for port 8510, for devices on your home network only, not the internet. The wizard shows "Allowed on your home network" when it's done.
  3. Scan the QR code shown in the wizard, or open the address it shows and type the PIN.
  4. VPN on the PC or phone? Turn it off while using the hub.

Fallback (if the wizard can't add the rule): open PowerShell as administrator and run this one line:

New-NetFirewallRule -DisplayName "Stark World Engine Creator Hub 8510" -Direction Inbound -Protocol TCP -LocalPort 8510 -RemoteAddress LocalSubnet -Action Allow -Profile Any

It opens port 8510 to your local network only, not the internet.

The QR code says it "was already used or has expired"

Each QR code logs in one phone, once, within 15 minutes. Type the PIN on the login page instead, or make a new QR code (open the wizard's Your phone remote step again, or run python creator_hub.py --qr).

An old link with ?pin= in it doesn't log me in

That's on purpose: the PIN is never accepted from a link any more. Scan a fresh QR code or type the PIN on the login page.

The hub asks for the PIN again

Your phone stays logged in until the hub is restarted. After a restart, scan a new QR code or type the PIN.

The hub says the PIN is wrong / I'm locked out

The PIN is shown in the Setup Wizard. It is hub_pin in config.json in the studio folder, unless you moved it to your private app-data folder with python gs_common.py --move-secrets. After 5 wrong tries within 10 minutes from one device, that device's PIN logins are locked for 15 minutes; wait, then try again with the right PIN.

The phone camera doesn't work

The Camera tab needs the HTTPS VDO.Ninja link the hub provides and an internet connection. Allow camera access when Safari asks.

OBS doesn't start or stop recording from the phone

  • OBS must be open, using Profile > Stark_Profile.
  • The websocket must be on: in OBS, Tools > WebSocket Server Settings > "Enable WebSocket server" on port 4455. Running the Setup Wizard's camera step (or python obs_bridge.py) with OBS closed sets this up for you; restart OBS afterwards.

The auto editor does nothing

  • Is FFmpeg installed? The Setup Wizard's Check your tools step shows it and can install it. Or run ffmpeg -version in a new terminal; if it's not found, winget install Gyan.FFmpeg, then open a new terminal. You can also set the full path to ffmpeg.exe as "ffmpeg" in config.json.
  • Are your recordings in raw_clips/? The editor reads only that folder.
  • It waits until a file stops growing. Stop the recording, then give it a moment.
  • Each recording is edited only once (even if renamed). To get a new edit, record a new take.
  • Only one watcher runs at a time; check .claude/editor.log in the studio folder for details.
  • Run python auto_editor.py --probe to see which video encoder it will use.

Captions are only a title, not my words

Add a .srt subtitle file with the same name next to the clip, or install the free local speech-to-text: pip install faster-whisper.

YouTube upload doesn't happen

  • You need your own free Google Cloud Desktop app OAuth client saved as client_secrets.json in the studio folder. The Setup Wizard's YouTube step walks you through it, or run python publishers.py --setup-wizard for a checklist.
  • Uploads only happen after you Approve in the hub.
  • Uploaded videos are private (and scheduled if you picked a time). Check YouTube Studio > Content.
