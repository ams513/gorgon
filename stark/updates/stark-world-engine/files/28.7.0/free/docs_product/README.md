# Stark World Engine

An offline 3D and 2D game builder. Everything runs on your computer; games export as one HTML5 file that plays in any current browser.
Editions: **Free**, **Pro** ($30) and **Studio** ($50). Start with `QUICKSTART.md`; the full manual is `USER_GUIDE.md`.

## What's new

All of these are in every edition, Free included, and work inside the exported one-file cartridge.

- **Logic tab: when / then blocks.** "When the player enters this area, open the door, play a sound, start a dialogue" with no scripting. Triggers are stored in the world data (`triggers`) and run in Play mode and in the export. (User guide 8.8)
- **Cutscenes.** A timeline of camera moves, lines of text, walking people, sounds and fades. Esc skips; skipping still applies the end state. (8.9)
- **More behaviours.** People can patrol a path, follow, run away or act as a fighting companion; enemies can patrol, guard a post or run when hurt; a person can run a shop that buys and sells. (8.10)
- **Three new starter games.** *The Missing Bell* (mystery village), *Cinder Crypt* (dungeon crawl) and *Pennant Run* (time trial). They are in World tab > Start from a template. (13)
- **Accessibility options in every exported game.** Remappable keys, a colour-blind palette (red-, green- or blue-weak), subtitles (on, large, off), and slow mode (75% or 50%). (10.1)
- **Achievements and a local high-score table.** Ten built-in achievements plus your own, a top-10 score table (fastest time first for time trials), kept in the player's browser. (10.1)

Older games load unchanged: every new field is optional.
