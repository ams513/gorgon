# Activating Stark World Engine 28.7.0

Stark World Engine works the moment you unzip it - with or without a key. A key registers your copy: Pro and Studio
keys export every level with no note and unlock the Godot 4 / UE5 exporters.

## Pro and Studio downloads come activated
The Pro and Studio zips already contain their key (`key.txt` next to `studio_app.py`). There is nothing to wait for
and nothing is sent by e-mail: unzip, start the studio, and **Export** shows your edition.

## Got a key as text (a gift, a re-issued key, or an older Standard key)?
1. It is ONE line of text that starts with `GS1-`.
2. Start the studio (`START_STARK_WORLD_ENGINE.bat` on Windows), open **Export > Activate**, paste the key and
   press **Activate**. The message tells you exactly what that key unlocks. Or save it as `key.txt` next to
   `studio_app.py`; the studio reads it when it starts.

## Editions
- Free: the whole builder; HTML5 cartridges export the first level with a small closable note.
- Pro: every level, no note, Godot 4 and UE5 project export, example cartridges.
- Studio: everything in Pro + the Windows creator suite.
- Standard is no longer sold. A Standard key you already have keeps working as before: every level, no note
  (Godot/UE5 export are part of Pro and Studio).

## Good to know
- No internet, no account, no server: the key is checked on your computer against a public signature key that
  ships inside `licensing.py`. Nothing is sent anywhere, ever.
- A missing, mistyped or damaged key never stops the program: it shows "unregistered" and keeps the Free
  features. Paste the key again in one piece to fix a typo.
- Each copy carries a buyer reference, so please keep your download and key to yourself.
- Lost your key? Contact the seller with your order number; it is re-issued offline.
- Honest note: keys, buyer references and the compacted JavaScript make casual sharing harder. They are not
  unbreakable copy protection. There is no anti-debugging, no anti-virtualisation and no online check that could
  lock you out. The Python source ships readable because compiled .pyc files only run on one exact Python version.
