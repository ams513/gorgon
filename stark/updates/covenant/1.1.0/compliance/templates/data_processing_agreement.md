## Processor obligations (Art. 28(3))

1. Process only on the controller's documented instructions, including on transfers; tell the controller if an
   instruction appears to infringe the law.
2. Ensure everyone authorised to process the data is bound by confidentiality.
3. Take the security measures in Annex 2 (Art. 32).
4. Engage sub-processors only with the controller's prior [specific / general] written authorisation, on the
   same terms; remain liable for them. Current sub-processors: [LIST].
5. Help the controller answer data-subject requests (access, rectification, erasure, restriction,
   portability, objection) within [X] days.
6. Help the controller with security, breach notification (notify the controller without undue delay and
   within [24-48] hours of becoming aware), DPIAs and prior consultation.
7. At the end of the service, delete or return all personal data, and delete existing copies, unless law
   requires storage; confirm in writing.
8. Make available all information needed to demonstrate compliance and allow audits and inspections.
