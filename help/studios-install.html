Stark World Engine: Install on Windows, macOS and Linux

Stark World Engine runs from one folder on your own computer and opens in your browser. Nothing is installed system-wide.

What you need

  • Windows 10 or 11: nothing else. Python is included in the download.
  • macOS or Linux: Python 3.10 or newer (free, from python.org or your package manager).
  • A browser with WebGL2: a current Chrome, Edge or Firefox.
  • Optional: Godot 4.2+ for the Godot export, Unreal Engine 5.4+ for the UE5 export. The Studio edition's creator suite needs Windows 10/11, FFmpeg and OBS Studio 30+.

Windows 10 / 11

  1. Right-click the zip you downloaded (for example Gorgon_Studios_Pro_Holiday_v28.zip) and choose Extract All... > Extract. Put it somewhere you own, such as Documents or the Desktop, not C:\Program Files.
  2. Open the new folder and double-click START_GORGON_STUDIOS.bat.
  3. A small black window opens, runs a quick setup check and opens the studio in your browser. Leave the black window open while you work; it is the studio's engine. Close it when you're done.

If Windows shows "Windows protected your PC", click More info > Run anyway. SmartScreen warns about any new download that hasn't built up a reputation yet. The .bat files are short plain-text scripts you can open in Notepad to read first.

macOS

  1. If you don't have Python 3.10 or newer, download the macOS installer from python.org > Downloads and click through it.
  2. Unzip the download and move the Stark World Engine folder out of Downloads, for example into Documents.
  3. Double-click start_gorgon_studios.command. The first time, macOS may say it is from an unidentified developer: right-click the file > Open > Open. You only do this once.

Linux

  1. Check your Python in a terminal: python3 --version. If it is below 3.10, install a newer one with your package manager (for example sudo apt install python3, sudo dnf install python3 or sudo pacman -S python).
  2. Unzip the download, open a terminal in the folder and run bash start_gorgon_studios.sh.

If the browser doesn't open

Copy the address printed in the black window or terminal (like http://127.0.0.1:8505) into your browser. The studio only answers on your own computer, so it won't load from another device.

Removing it

Copy your My_Games folder (and My_Assets, if you imported models) somewhere safe, then delete the Stark World Engine folder.

Still stuck?

Write to hello@starkforall.com with your operating system, browser and edition, what the black window (or Terminal) printed, and doctor.log / launcher.log from the studio folder if you can. Please never post your licence key in a public comment.
