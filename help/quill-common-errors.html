Stark Quill: Common errors and fixes

The short answers to what writers ask most. Your book is safe in every one of these: each chapter is a plain file in Documents\My_Books, with backups beside it.

Quill closed (or the power went out) while I was typing
Start Quill again. It restores the last save it received and shows a note at the top when it did. The browser also keeps a copy of what you typed since the last save and sends it again.
A chapter is missing
It may have been renamed, moved or deleted. Look under Backups > Deleted chapters, or restore a snapshot (see Backups).
Pro stopped working
Licence shows the end date. If the 12 months have ended, Quill is on Free and every book still opens and exports as text, Markdown and a web page.
The key won't paste
Mail programs sometimes break long lines. Copy the key again as one single line starting with GQ1.
My phone won't connect (Pro)
Phone and PC must be on the same Wi-Fi. On the PC: More > Write from your phone, then follow the steps in that window: scan the code and type the PIN.
AI notes say no model is running (Pro)
Install Ollama from ollama.com, then run ollama pull llama3.2 once. The rest of the Lore panel works without it.
My characters' names are underlined
Each book has its own dictionary, dictionary.txt in the book folder. Add a word from the Lore panel or edit the file. Spelling follows the book's language in Book details.
An empty chapter is missing from my export
Quill leaves out chapters with no text yet and tells you which ones.
The PDF looks different on my Mac
Palatino Linotype ships with Windows. Elsewhere Quill uses another installed serif it can embed. Word or EPUB export are alternatives.
"Update failed"
Nothing was changed; Quill tries again the next day.

Still stuck?

Write to hello@starkforall.com with your Quill version (About), Windows, macOS or Linux, and what you were doing when it happened. I never need your book to help, so please don't send it unless you want to.
