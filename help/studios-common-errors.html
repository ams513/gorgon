Stark World Engine: Common errors and fixes

Start here: the setup check runs every time the studio starts, and inside the studio you can press ? and click Fix my setup. It names the problem and the fix in plain words, and saves its report as doctor.log.

"Stark World Engine has to be extracted from the zip first"
You started it inside the zip preview. Right-click the zip > Extract All... > Extract, then double-click START_GORGON_STUDIOS.bat in the new folder. On a Mac, move the folder out of Downloads (for example into Documents) and start again.
"Stark World Engine is in Program Files..." or "This folder is read-only..."
The studio saves your games next to itself. Press Y: it copies itself to Documents\GorgonStudios and starts from there. The original folder isn't changed.
"Stark World Engine files are missing or damaged"
Usually an antivirus quarantined a file right after unzipping. Restore it (Windows Security > Virus & threat protection > Protection history), or download the zip again and extract it into a new folder, then copy your My_Games across.
"All ports 8505-8520 are in use"
Close the programs it names (often several old studio windows), or restart the PC, then start again.
"No Chrome, Edge or Firefox found"
Install a current Chrome, Edge or Firefox (all free) and start again.
Windows: "This PC doesn't have it yet" (Python)
The built-in Python folder is missing or blocked. Press Y and the launcher fetches the official Python from python.org into the Stark World Engine folder only, or extract the zip again into a new folder.
macOS: "unidentified developer", or Python isn't installed
Right-click start_gorgon_studios.command > Open > Open. If Python is missing, the launcher opens python.org for you; install it and double-click the launcher again.
Linux: "Stark World Engine runs on Python 3.10 or newer"
Install a newer Python with your package manager, then run bash start_gorgon_studios.sh again.
The stage is black, or there is a WebGL error
The 3D builder needs WebGL2. Use a current Chrome, Edge or Firefox, turn on hardware acceleration in the browser's settings, and update your graphics driver. Remote desktop sessions and some virtual machines don't provide WebGL2. 2D worlds still work.
It's slow on an older laptop
Press Esc in Play mode and set Graphics to Low.
No sound
Browsers block sound until you click the page. Click the stage once, check the tab isn't muted, and check Sound: on in the in-game menu (Esc).
"Not saved: ..."
Give the game a name, make sure the studio isn't running from inside the zip or Program Files, and if the folder is in OneDrive or Dropbox, move it somewhere local.
"Your key (key.txt) is not valid, so the studio runs as Standard"
Nothing is lost. See Activation and keys.
The Godot project looks dark or won't run
Use Godot 4.2 or newer; its Forward+ renderer needs Vulkan or Direct3D 12. The first open compiles shaders, so give it a moment. Only your first level is exported, as a starting scene, by design.
Unreal: the Stark menu is missing or the level is empty
Use Unreal Engine 5.4 or newer and say yes if it asks to enable plugins. Then choose Stark World Engine > Build level from world.json. I haven't yet run this export in a real UE5 install myself, so if it fails, please send me Saved/Gorgon/build_report.json and the Output Log.

Still stuck?

Write to hello@starkforall.com with your operating system, browser and edition, what the black window (or Terminal) printed, and doctor.log / launcher.log from the studio folder if you can. Please never post your licence key in a public comment.
